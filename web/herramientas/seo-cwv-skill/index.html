Auditoría SEO · Core Web Vitals

Le enseñas a la IA a revisar cualquier página web y decirte, en palabras que entiendes, qué tiene mal.

Qué hace

  • Le das la dirección de un sitio y en menos de dos minutos te dice qué está pasando: velocidad, SEO y si está listo para que la IA lo recomiende.
  • Te lo explica clarito (no en lenguaje de programador) y te entrega un reporte profesional en PDF con tu nombre, listo para enseñárselo a un cliente o a tu equipo.
  • Opcional: además de auditar, puede aplicar los arreglos en WordPress para poner los Core Web Vitals en verde — con respaldos y tu aprobación.

Qué necesitas

  • Claude Code + una suscripción de Claude.
  • Node.js 18 o superior (nodejs.org).
  • Una API key gratuita de PageSpeed Insights (Google). Consíguela aquí
  • Chrome, Chromium o Edge instalado (para generar el PDF).

01 · Qué es

Una skill de Claude Code con dos modos: AUDITAR (solo lectura, seguro) y OPTIMIZAR (aplica arreglos en WordPress/cPanel, con red de seguridad). Multisitio: cada cliente es un archivo de configuración, así puedes revisar varios sitios sin mezclarlos.

02 · Cómo se usa

En Claude Code, pídele:

usa la skill seo-cwv para https://el-sitio-que-sea.com

O con el comando corto:

/auditar-sitio https://el-sitio-que-sea.com

Cuando quieras aplicar los arreglos (con aprobación):

/optimizar-sitio

03 · Instalar

TerminalApp de escritorio

1) Agrega el catálogo de El Profe Abraham (una sola vez):

/plugin marketplace add elprofeabraham/herramientas

2) Instala la skill:

/plugin install seo-cwv@elprofeabraham

En la app de escritorio es igual: abre el panel con /plugin, busca seo-cwv en el catálogo elprofeabraham y dale Instalar.

Alternativa: clonar

Si prefieres copiar la carpeta a mano:

git clone https://github.com/elprofeabraham/herramientas.git
# copia  plugins/seo-cwv/skills/seo-cwv  dentro de tu carpeta ~/.claude/skills/
